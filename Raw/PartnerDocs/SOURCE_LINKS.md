## Source rule

Partner-specific code must be based on verified documentation or live account/API explorer behavior.

Do not invent request fields, signature schemes, webhook payloads, endpoint paths, model names, phone-number rules, or authentication mechanisms.

If two official pages conflict, record the conflict and verify against the current API explorer/dashboard before implementation.
